# KONYSHEV ART

Самостоятельный статический сайт-портфолио Юры Конышева. В него перенесены главная страница, 16 работ и выставка из текущего сайта на Tilda. Для выставки в Московской городской Думе создана отдельная страница `mgd-2025.html` с локальной копией видео. Сайт работает без сборки, базы данных и платной CMS.

## Как открыть сайт

Самый простой способ — открыть `index.html` двойным щелчком. Если на компьютере установлен Python, для полноценной локальной проверки можно открыть PowerShell в этой папке и выполнить:

```powershell
python -m http.server 8080
```

Затем открыть `http://localhost:8080`.

## Как добавить новую работу

### 1. Подготовить изображение

- Экспортируйте фотографию картины в JPG или WebP.
- Желательно: ширина 1600–2400 px, профиль sRGB, размер до 1–1,5 МБ.
- Назовите файл латиницей без пробелов, например `17-new-work.webp`.
- Положите его в папку `assets/artworks/`.

### 2. Добавить описание

Откройте `content.js`. Внутри массива `artworks` скопируйте один готовый блок и вставьте его перед закрывающей квадратной скобкой. Пример:

```js
{
  id: "new-work",
  image: "assets/artworks/17-new-work.webp",
  status: "catalog",
  ru: {
    title: "Название новой работы",
    meta: "Холст, масло · 80 × 100 см · 2026"
  },
  zh: {
    title: "新作品名称",
    meta: "布面油画 · 80 × 100 厘米 · 2026"
  },
  ar: {
    title: "اسم العمل الجديد",
    meta: "زيت على قماش · 80 × 100 سم · 2026"
  }
},
```

Важные поля:

- `id` — уникальное короткое имя латиницей;
- `image` — путь к файлу изображения;
- `status: "private"` — работа в частной коллекции;
- `status: "catalog"` — обычная работа в каталоге;
- `ru`, `zh` и `ar` — русский, китайский и арабский варианты названия и подписи.

Сохраните файл и обновите страницу. Счётчик работ и галерея обновятся автоматически.

## Как поменять текст сайта

Все короткие подписи и переводы находятся в начале `content.js`, в блоке `translations`. Тексты раздела «О художнике», названия меню, выставки и будущих разделов меняются там же.

## Как добавить выставку

Сейчас с Tilda перенесена одна запись — персональная выставка в Московской городской Думе (2025). Её разметка находится в `index.html` в секции `id="exhibitions"`. Для второй выставки скопируйте блок `<article class="exhibition-card">…</article>`, поменяйте год и добавьте новые ключи переводов в `content.js`.

Когда выставок станет больше трёх, стоит вынести их в отдельный массив по тому же принципу, что и работы. Тогда новые записи можно будет добавлять без редактирования HTML.

## Публикация

Папку можно загрузить на любой хостинг для статических сайтов. В корне публикации должны лежать `index.html`, `styles.css`, `content.js`, `app.js` и папка `assets`.

Китайская и арабская версии сделаны как редакционные переводы. Перед публичным запуском желательно отдельно согласовать с носителями языков написание имени «尤拉·科内舍夫» / «يورا كونيشيف» и названия работ.
