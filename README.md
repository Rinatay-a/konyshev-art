# KONYSHEV ART

Самостоятельный двуязычный сайт-портфолио художника Юры Конышева.

В проект перенесены:
- информация о художнике;
- 16 живописных работ;
- выставка в Московской городской Думе;
- отдельная страница выставки с видео;
- русский и китайский языки;
- адаптивная версия для телефонов.

## Добавление новой работы

Изображение помещается в `assets/artworks/`, а название, техника и переводы добавляются в массив `artworks` файла `content.js`.

Китайская версия сделана как редакционный перевод. Перед публичным запуском желательно согласовать с Юрой китайское написание имени и названия работ.
